# Fixtures

Wikitext from English Wikipedia, used to test article parsing. Long articles are cut after a few
sections.

- `mount-rainier.wiki`: [Mount Rainier](https://en.wikipedia.org/wiki/Mount_Rainier)
- `nintendo.wiki`: [Nintendo](https://en.wikipedia.org/wiki/Nintendo)
- `mercury.wiki`: [Mercury](https://en.wikipedia.org/wiki/Mercury) (disambiguation page)

The text is by Wikipedia's contributors (see each article's history) and is licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), not this repo's MIT licence.
